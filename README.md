# 文字数カウンター

文章の文字数、行数、段落数をブラウザ上で確認できる静的Webアプリです。

## ローカルで起動

依存関係はありません。`index.html` をブラウザで直接開いてください。

ローカルサーバーで確認する場合は、対象フォルダで次のいずれかを実行します。

```text
py -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## Cloudflare Pagesで公開

このアプリは静的ファイルだけで動くため、ビルド設定は不要です。

1. Gitをインストールするか、GitHub Desktopを用意する。
2. このフォルダをGitHubの新しいリポジトリへアップロードする。
3. Cloudflareにログインし、`Workers & Pages` から `Create application` → `Pages` → `Import an existing Git repository` を選ぶ。
4. GitHubリポジトリを選択する。
5. Framework presetは `None`、Build commandは空欄、Build output directoryは `/` にする。
6. `Save and Deploy` を実行する。

公開後はCloudflareが発行するURLでアクセスできます。独自ドメインを使う場合は、Cloudflare Pagesのプロジェクト設定から追加します。

この環境ではGitが未インストールのため、現時点ではGitHubへのpushは実行していません。GitHub Desktopを使う場合は、このフォルダを選択してリポジトリを作成し、4ファイルと `.gitignore` をcommitしてからGitHubへ公開してください。

## カウントの定義

- **文字数**: 空白文字と改行を除いた、見た目に近い文字単位でカウントします。
- **全体文字数**: 空白・改行を含めた文字数です。
- **行数**: 入力が空の場合は0行。改行で分かれた行を数えます。
- **段落数**: 空行を除いた行の数です。文章の段落を簡易的に確認するための値です。
- 入力内容はブラウザ内だけで処理し、サーバーへの送信や保存は行いません。

## 本番公開と広告収入

広告を掲載する前に、次の準備が必要です。

1. HTTPS対応のホスティングと独自ドメインを用意する。
2. サービスの使い方や文字数の定義を説明するページを追加する。
3. プライバシーポリシー、広告Cookieの説明、必要な同意管理を整える。
4. `ads.txt` と広告事業者のポリシーを確認する。
5. Google AdSense等の審査に通過してから広告スクリプトを追加する。
6. 広告が入力欄や操作ボタンと誤認されない配置にする。

広告のクリックを促す文言は設置せず、広告表示が入力体験、表示速度、アクセシビリティを損なわないことを確認してください。AdSenseの要件は変更される可能性があるため、申請前に公式の最新情報を確認します。

## 手動確認項目

- 日本語、英数字、半角・全角空白、改行、連続改行、絵文字
- 入力、貼り付け、リセット、Tabキーでの操作
- スマートフォン幅での表示とテキストの折り返し
- ライトモードとOSのダークモード設定
- 開発者ツールのコンソールエラーと不要なネットワーク送信がないこと
